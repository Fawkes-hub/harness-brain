# 术语表

| 术语 | 含义 | 不要和什么混淆 |
| --- | --- | --- |
| **端**(endpoint) | 一台运行 harness 的机器,如 Mac、手机 | 不是"角色" |
| **harness** | 跑模型的宿主程序,如 DSH、Octop、Pi | 不是"端" |
| **角色**(role) | 语气与职责的集合,如 `assistant`、`engineer` | 不是权限 |
| **atom** | 一条不可变记忆,一个文件 | 不是"视图" |
| **视图**(view) | 由 atoms 派生出的 Markdown 汇总,可随时重建 | 不是真相 |
| **inbox / outbox** | 端侧待提交队列(outbox);v1 是服务端侧收集区(inbox) | 两者都是"暂存",不是真相 |
| **brief** | 会话开头注入的摘要(规范+索引+主机笔记) | 不是全量记忆 |
| **recall** | 按时间取对话摘要,回答"上次聊到哪" | 不是事实检索 |
| **consolidate** | 把 inbox/outbox 归并进视图与主题文件 | 不是"删除" |
| **supersede** | 新记录取代旧记录,旧的保留可追溯 | 不是"覆盖" |
| **deprecated** | 标记失效,默认不检索 | 不是"物理删除" |
| **scope** | 记录的可见范围(当前只实现 `public`) | 当前**未启用**过滤 |
| **stale** | 缓存/副本已过期,必须提示用户 | 不是"不可用" |
| **边缘**(edge) | 反向代理那一层,可选 | 不是核心 |
| **单写者** | 只有服务端进程能改数据 | 不是主从复制 |
